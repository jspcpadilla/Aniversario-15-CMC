# CMC · 15 años

Invitación interactiva de aniversario para Centro Médico Cognitivo e Investigación.

## Incluye
- Marco elegante construido con HTML/CSS/SVG; no es una imagen estática.
- Responsive para escritorio, tablet, móviles y landscape.
- Escena de apertura, carga y bienvenida.
- 15 velas interactivas con valores institucionales.
- Contador y barra de progreso 0/15 → 15/15.
- Celebración de partículas y transición a la invitación.
- Invitación con scroll interno.
- Google Maps, calendario `.ics` y compartir.
- Confirmación mediante Microsoft Forms.
- Sonido opcional con Web Audio API.
